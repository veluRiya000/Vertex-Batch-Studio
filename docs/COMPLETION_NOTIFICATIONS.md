# 完成提醒

左下角「设置 → 完成提醒」可设置 Windows 原生通知，默认开启；已保存的开关选择继续保留。

- **所有批次完成**：生图与 Harness 分别统计，各自队列的已提交任务全部结束后提醒，互不阻塞。运行期间新提交的同类任务加入本轮统计；草稿与没有在途云端请求的暂停任务不计入。暂停但云端请求尚未结束或状态未确认时，仍等待该请求；单独暂停不会发出完成提醒。
- **每批次完成**：一个生图批次或一整轮 Harness 任务结束后提醒。Harness 内部的工具步骤、模型轮次与续传片段不会逐个提醒。
- 可分别启用生图与 Harness，也可关闭失败提醒。用户取消不播放完成提示。
- 三种内置音效；可导入 WAV（PCM）或 MP3，最大 5 MB，最长播放 10 秒。导入后复制到受管理的数据目录，原文件移动后不受影响。
- 「试听」只播放声音；「发送测试提醒」发送一条真实系统通知，即使总开关关闭也能测试。

窗口缩到托盘时后台继续提醒；完全退出后停止本地提醒服务。Windows 通知权限、勿扰模式和系统音量决定横幅与声音的实际表现。通知不包含提示词、文件正文或云端凭证。

## 实现与边界

配置保存在 `settings.json` 的 `notifications` 中，音频及观察账本位于应用数据目录 `data/notifications/`。后台独立监控完成状态，不依赖 React 视图挂载或 SSE 重连。旧历史不会在首次开启时集中提醒，观察状态跨重启保存。

派发前落盘，避免刷新或重启重复提醒。Windows 派发与本地落盘无法构成同一个事务；派发瞬间崩溃或系统拒绝可能丢失该次提醒，而不会无限重放。系统发送错误显示在提醒设置页。

Windows 接收端使用 WinRT Toast；仅为当前用户登记 Vertex Batch Studio 的通知标识。通过隐藏的系统 PowerShell 调用，无新增 Python/Node 运行依赖，无终端窗口。动态内容经 JSON 标准输入传递，导入音频只从受管理目录播放。
