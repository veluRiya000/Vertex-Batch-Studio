# Vertex Batch Studio 0.3.5 · 生图版

- 长项目优先打开最近 20 条任务，滚动浏览旧记录，也可从生成队列直接跳到指定任务。
- 参考图和生成结果按需加载缩略图，限制同时读取的数量。点开预览时读取原图，重新解码后的结果会更新预览。
- 顶栏的「账单报告」和「赠金」在浏览器中打开 Google Cloud 官方页面。
- 主分支与新安装器聚焦批量生图。旧版 Harness 保留在 [feature/harness-batch](https://github.com/veluRiya000/Vertex-Batch-Studio/tree/feature/harness-batch) 和 [v0.3.4](https://github.com/veluRiya000/Vertex-Batch-Studio/releases/tag/v0.3.4)。安装器支持覆盖升级，现有项目、图片、设置和凭证保存在原用户数据目录。

## English

- Large projects start with the 20 newest tasks. Scroll into earlier history or jump directly to a task from the queue.
- Reference and generated images load resized previews near the viewport with bounded concurrency. Opening a preview loads the original, and re-decoding refreshes the displayed result.
- Billing Reports and Credits in the title bar open Google Cloud in your browser.
- The main branch and the new installer focus on batch image generation. The previous Harness build is available on [feature/harness-batch](https://github.com/veluRiya000/Vertex-Batch-Studio/tree/feature/harness-batch) and in [v0.3.4](https://github.com/veluRiya000/Vertex-Batch-Studio/releases/tag/v0.3.4). In-place upgrades retain projects, images, settings, and credentials in the original user data directory.
