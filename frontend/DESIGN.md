# 已确认的界面设计

确认日期：2026-10-03。用户已确认采用“晴蓝 · 明亮方案”。正式 React 前端沿用本约定，已连接本机后端生成流程。

## 图标和模型标识

- 常规图标采用圆角细线风格。
- 左上角 Logo 使用叠放画幅与金色光点。
- 模型名称旁保留完整四角星，显示尺寸为 22 × 22 像素，避免通用图标样式将它压缩到 16 像素。
- 星星内部使用蓝、紫、粉、金、绿的完整渐变，缓慢流动，一圈约 8 秒。
- 边缘仅使用白色柔光，不使用彩色阴影、内部白色块或沿模型按钮边框运行的流光。
- 白边绘制在彩色填充外侧，保留星星原来的轮廓。
- 系统要求减少动画时，停止循环流动，保留静态渐变。

## 输入框和参数菜单

- 输入框、参数按钮、弹出菜单和菜单选项统一圆角。
- 比例与分辨率均可选择；数量选项只显示 `1`、`2`、`3`、`4`，“张”显示在按钮外。
- 比例菜单分为横屏和竖屏两列，比例文字保持清晰。
- 横屏保留 `16:9`、`4:3`、`3:2`、`21:9`；竖屏保留 `9:16`、`3:4`、`2:3`、`9:21`。
- 两列下面单独放置 `1:1 · 方形`；菜单最底部放置“匹配参考图”。
- 不在菜单中显示 `4:1`、`1:4`、`8:1`、`1:8`、`5:4`、`4:5`。
- 隐藏提示词编辑区域内部的方形焦点框，保留整个输入容器的圆角焦点高亮。
- 移除手动拖动输入框大小的角标；输入内容增加时自动长高，删减时自动收回。
- 选择菜单支持键盘操作、点击外部关闭，并避免窄窗口下越界。

## 正式界面接入

- React 前端连接素材、批次、任务、提交、监控及结果预览接口；旧的配色样稿保留为设计参考。
- 公共参考图库提供列表／窗格切换，记住显示模式。点击条目或图片打开预览及原文件路径，只有独立加号按钮加入输入框。图库内拖动只排序，不会拖入输入框误添加；本地图片文件仍可直接拖入输入框。
- 三类参考图均支持拖动换位，按分类保存到本地，不移动或重命名原图。两种视图共用顺序；键盘 Alt＋方向键也能换位，保存失败恢复原顺序并提示。
- “匹配参考图”使用第一张参考图的实际尺寸，选择菜单内最接近的可用比例；不向后端发送 `reference`。未选图片时提示添加。
- 每次发送仍对应一个提示词加参考图的任务。将当时的参数随任务保存，之后修改参数不改变已有任务。
- 侧栏右边缘连续拖动调宽，最窄保留 36px 细条和左下展开入口；宽度保存到本地。快捷收起／展开按钮放在左下角，窄窗口使用带遮罩的浮动侧栏。
- 当前项目可反复点击展开／收起任务树，保持正在编辑的提示词和参考图。
- 删除公共图库、主区域、队列中的空状态说明文案。左上“关于”只显示连接信息和检查连接，左下独立“设置”提供主题、语言、桌面行为和 Google Cloud 服务账号配置。
- 星空图标使用完整四角轮廓、缓慢旋转的 SVG 渐变和白色边缘柔光。系统要求减少动画时停止旋转。
