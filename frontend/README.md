# 界面接入位置

后端已预留 HTTP 接口与 SSE 事件。React/TypeScript 界面和 Electron 桌面包装在后续课程实现，本目录目前不包含界面或可执行程序。

用户已确认界面配色、模型星星效果及参数菜单规范，详见 [设计约定](DESIGN.md)。正式界面实现时按该约定落地。

Electron 主进程启动 `python -m backend serve --port 0`，从启动信息读取随机端口与令牌。令牌由主进程持有；通过受控 IPC 转发界面操作，不向任意网页开放本地后端。

关闭窗口时隐藏窗口并保留主进程及 Python 子进程。托盘菜单提供“打开窗口”和“退出”。明确退出时向后端请求 `/shutdown`，等待子进程结束；不能通过直接关闭窗口来终止监控。
